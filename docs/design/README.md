# GeoSweep shape studies

These are standalone previews of the shape directions explored before changing the game. Open either HTML file in a browser. They include their geometry code and a view toggle for comparing polygon outlines; the sculpted study also supports rotation.

- [Polygon prisms](prism-lineup.html): values 3–13 are extruded polygons, with a cube for 4. Spark and Sphere are exploratory representations for 1 and 2.
- [Sculpted shapes](sculpted-lineup.html): varied wedges, crystals, reactors, crowns, shields, beacons, spires, lanterns, and towers retain the corresponding polygon bases. These labels describe concepts, not approved final shape names.

The live game still uses its existing geometries. The polygon-based direction and the exact representations for 1 and 2 remain exploratory. Naming guidance is in [GeoSweep language](../GEOSWEEP_LANGUAGE.md).

The game implementation was checkpointed at `5598339` on `codex/suipi-tug-of-war`. Further exploration continues on `codex/geosweep-shape-exploration`.
